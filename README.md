# clickMe

A simple website with one goal: click as many times as you can.

Built with React and Vite.

## Getting started

Make sure you have [Node.js](https://nodejs.org) installed, then:

```bash
git clone https://github.com/notMehrzad/clickMe.git
cd clickMe
npm install
npm run dev
```

Open the local link it prints.

## Tech

- React
- Vite
